# 성적분석

**사이트: https://whdtlr4979-commits.github.io/grade-analyzer/**

내신(나이스 교과학습발달상황 엑셀)과 모의고사(전국연합학력평가 반별 성적일람표 PDF)를 올리면 성적을 분석해 보여 줘요.
- 학생별 내신 평균 등급과 학기별 추이
- 모의고사 영역합과 과목별 등급 추이
- 반 전체 표, 전교생 순위(상위권·등수 증감), 예상 등급 계산

## 성적은 각자 PC에만 저장돼요

- 이 사이트는 화면과 프로그램만 내려줘요. 엑셀·PDF는 **브라우저 안에서** 읽고, 읽어 낸 성적은 **그 PC의 그 브라우저에만** 저장돼요.
- 서버나 이 저장소로는 아무것도 보내지 않아요.
- PDF·엑셀을 읽는 도구(pdf.js 4.10.38, SheetJS 0.18.5)도 파일 안에 들어 있어서, 처음 연 뒤에는 외부 사이트에 접속하지 않아요.

## 쓰는 방법

1. 위 사이트 주소를 크롬이나 엣지로 열어요. 즐겨찾기에 넣어 두면 편해요.
2. **성적 추가**에 파일을 끌어다 놓아요.
   - **내신**: 나이스 › 학교생활기록부 › 학생부 항목별 조회 › 교과학습발달상황 › XLS 저장 (반마다 한 파일)
   - **모의고사**: 전국연합학력평가 성적일람표(학급별) PDF (3·6·9월, 10월 양식). PDF에 학년·반이 비어 있으면 파일 이름에 `2학년 3반 6월`처럼 적어 주세요.
3. 학생별 · 반 전체 · 전교생 탭으로 보고, **인쇄 · PDF 저장**으로 A4 인쇄해요.
   - 전교생 순위·증감은 모의고사 **표점합**, 내신 **전체 평균** 기준으로 고정이에요. 열 제목을 누르면 보이는 순서만 바뀌어요.
   - 반 전체·전교생 표는 **엑셀로 저장**할 수 있어요.

## 꼭 알아 둘 점

- **PC·브라우저마다 따로 저장돼요.**
  - 다른 PC로 옮기려면 **백업 › 백업 파일로 저장**한 뒤, 다른 PC에서 **백업 파일 불러오기**를 해요.
- **브라우저의 "쿠키 및 기타 사이트 데이터"를 지우면 성적도 지워져요.** 가끔 백업 파일을 남겨 두세요.
- **백업 파일은 비밀번호로 잠겨 있지만**, 학생 개인정보가 들어 있으니 안전한 곳에 보관하고 이 저장소에는 올리지 마세요.
- **여러 명이 같은 PC·같은 브라우저를 쓰면** 다 쓴 뒤 **등록된 성적 › 펼치기 › 성적 데이터 삭제**로 지우세요.

## 보안

- **백업 파일은 비밀번호로 잠겨요.**
  - 백업할 때 정한 비밀번호(4자 이상)로 암호화해요. 방식은 PBKDF2-SHA256 25만 회 + AES-256-GCM이고, 브라우저 내장 Web Crypto를 써요.
  - 그래서 파일을 메모장으로 열어도 이름·성적이 보이지 않아요.
  - 불러올 때 비밀번호가 필요하고, **잊으면 열 수 없어요.** 비밀번호는 파일과 따로 보관하세요.
- **외부 전송 차단(CSP)**
  - 페이지에 "어떤 서버에도 접속·전송하지 말고, 이 파일 밖의 프로그램을 불러오지 말라"는 브라우저 규칙이 들어 있어요.
  - 그래서 실수로 외부 코드가 섞여도 성적이 다른 곳으로 나가지 않아요.
  - 링크로 페이지를 이동하는 것까지 막지는 못해요. 그래서 **이 저장소를 관리하는 GitHub 계정에 2단계 인증을 켜 두는 것**이 중요해요.
- 브라우저에 저장된 성적 자체는 암호화되지 않아요. PC의 Windows 계정에 비밀번호를 걸고, 자리를 비울 때 화면을 잠그세요.

## 새 버전 올리기 (관리자)

`index.html`을 새 파일로 바꿔 올리면 1~2분 뒤 사이트에 반영돼요. 선생님들은 새로 고침만 하면 되고, 저장된 성적은 그대로 남아요.
